    FNMT certificate won't download after the office visit: what to check

    Krepko · 11 November 2026 · ~9 min read
    In short. The FNMT certificate is downloaded from sede.fnmt.gob.es on the same computer and under the same user account where the request was made, and, according to FNMT's explanation, in the same browser too: the private key is stored in the Configurador FNMT-RCM program on that computer. According to FNMT, the certificate can be downloaded about an hour after your identity is verified at the office: in the form you enter your NIE number and first surname exactly as in the request, and the code from the FNMT email, and then the password you set when making the request. This password cannot be recovered. If you have forgotten it, and also if the computer was formatted or Configurador was uninstalled before the download, FNMT suggests starting again: make a new request and verify your identity at the office again with the new code (checked against the FNMT website on 11 November 2026).

    Your identity has been verified at the office, the code from the FNMT email is to hand, but the certificate will not download: the website shows an error in Spanish or the certificate never gets installed. According to FNMT's explanations, the download fails when the environment in which the request was made changes: a different computer or user account, a different or updated browser, the Configurador FNMT-RCM program having been uninstalled. Another cause is details or a password entered differently from the request.

    Below we look at what to check before making a new request and what the error messages mean. The whole route to the certificate is described in the article on the certificado digital; here we cover only the download. The information was checked against the FNMT website on 11 November 2026.

    We handle the whole process of getting an FNMT certificate: we submit the request from your device, prepare your submission for identity verification, accompany you to the office visit with interpretation, download the certificate onto that same device and make a backup there too. How this works is described on the service page “Digital certificate (firma digital)”. If you made the request yourself and got stuck at the download, go through the points below: some failures can be fixed without a new office visit.

    What to check before starting again

    Until the certificate has been downloaded, do not delete or reinstall anything at random. According to FNMT's explanation (question 1681), when the request is made, the Configurador FNMT-RCM program creates a key pair. The private key stays in its store on your computer, and during the download the program joins it to the issued certificate. No key, and the certificate will not install. If you uninstall Configurador before the download and the backup, you will have to go through the whole route again. The exception is the procedure with a copy of the .fnmt folder, described below.

    • The same computer and the same user account. FNMT states this condition explicitly on the download page. On a new laptop or under a different user account the certificate cannot be downloaded with this code: there you install a copy of a certificate that has already been downloaded, as described in the article on transferring the certificate.
    • The same browser, with no updates or resets. FNMT advises downloading in the same browser in which the request was made, and not changing anything in the system or in Configurador until the process is finished. For Firefox FNMT separately lists the causes of failure: a different Firefox profile, a reset browser primary password (contraseña maestra) and a Firefox update between the request and the download (question 1330).
    • Configurador is installed and starts. The program is installed before the request, from the “Configuración previa” page, with administrator rights, and after that the browser launches it by itself when it is needed. During the download the browser again asks for permission to launch it, and once permission is given the program asks for the request password. The password window sometimes stays behind the browser, so FNMT asks you not to click buttons repeatedly. The browser must accept all cookies, and FNMT advises turning off trackers (rastreadores) in it. If macOS will not let you install Configurador as a program from an unidentified developer, FNMT advises allowing it in the “Privacy & Security” settings. On a Mac with an M chip, after installation the program is launched from Launchpad, and it may ask you to install Rosetta.
    • Configurador does not ask for the password during the download. For this case FNMT describes a procedure without a new request (Windows): copy the .fnmt folder (FNMT gives the path as c:/usuarios/user_name/.fnmt) to another location, uninstall Configurador and delete that folder, install a fresh version of Configurador with administrator rights, put the saved folder back in its place and download the certificate again. Do not start this procedure without a reliable copy of the folder.
    • Details exactly as in the request. In the download form you enter the document number, first surname (primer apellido) and the code from the email (Código de Solicitud) and tick your acceptance of the terms of use of the certificate. FNMT asks you to enter the details exactly as in the request: the NIE or DNI number as 9 characters, with leading zeros if necessary, and the surname as it appears in the document.
    • About an hour has passed since the visit. On the general page of the procedure FNMT says that the certificate can be downloaded about an hour after identity verification, and on the identity verification page it advises downloading it as soon as possible.

    FNMT sets the same conditions for a renewed certificate: it is downloaded on the same computer and under the same user as when the renewal request was made, with the password set in that request. How the renewal itself works is explained in the article on renewing the certificado digital.

    What the error messages mean

    The FNMT website shows errors in Spanish. For several messages FNMT explains the cause and what to do in its questions and answers.

    What you see What it means according to FNMT What to do
    “No se ha encontrado el número de petición…” Your identity has not yet been verified at the office, or the office did not complete the procedure properly (question 1074) Check the details you entered; if less than an hour has passed since the visit, try again later. If the error does not go away, FNMT asks you to send it an email with the subject “NO GENERADO” stating your NIE, first surname, request code, and the date and office where your identity was verified; the address is in question 1074
    “No existe solicitud de Certificado para los datos que ha introducido” The code was not issued for this document number: for example, codes obtained for different NIEs have been mixed up (question 1073) Check that the code comes from the email for the request made for this particular NIE. The solution FNMT gives is a new request for your NIE and a new office visit with the most recent code received
    Firefox: “Este certificado personal no puede ser instalado…” There is no private key where the download is taking place: a different computer, browser or profile, the primary password has been reset, or Firefox was updated after the request (question 1330) For these cases FNMT suggests requesting the certificate again. But if you have simply used the wrong computer or profile, download where you made the request (the “Descargar Certificado” page)
    “No se ha encontrado la clave privada” The private key of the request has not been found: a different computer, browser, user account or Firefox profile, Configurador uninstalled or changed, a wrong request password, a reset Firefox primary password (FNMT page on this error) Download where you made the request, with the request password. If the key is not there either, according to FNMT the certificate cannot be downloaded and a new request is needed (question 1681)
    The certificate will not download although the details are correct, and an antivirus is running on the computer An antivirus may block writing to the Windows temporary folder, and an antivirus and a proxy may interfere with Configurador (question 1383, “Configuración previa” page) Add an exception in the antivirus or temporarily turn it off, do not use a proxy or allow Configurador in it; once you have the certificate, restore the settings

    When a new request cannot be avoided

    In these cases the certificate cannot be downloaded with the previous code, and FNMT suggests starting again: make a new request through Configurador and verify your identity at the office again with the new code.

    • You have forgotten the password set during the request. It is needed for the download, and it cannot be recovered (“Solicitar Certificado” page).
    • The computer was formatted between the request and the download. FNMT asks you not to do this: the private key is stored on the computer, in Configurador (“Configuración previa” page, question 1681).
    • Configurador was uninstalled before the download and the backup (question 1681).

    If the computer was changed or formatted before the office visit, FNMT advises not bringing the old code: make a new request and verify your identity with the new code (question 1044). If there are several codes for one NIE, bring to the office the most recent one obtained on the computer and in the browser where you will download the certificate (question 1045). Where to verify your identity again is explained in the article on where to verify your identity for a certificado digital.

    If you already have an FNMT certificate. An individual can have only one valid FNMT certificate: when a new one is issued for the same name, surnames and document number, the previous one is revoked automatically and the new one becomes valid (question 1053, section 132 of the FNMT rules for citizens' certificates). The exception is renewal in the last 60 days of validity: then the previous certificate remains valid until its expiry date. Bear this in mind if the old certificate still works on another device.

    The certificate has downloaded: check the installation and the backup

    During the download Configurador joins the certificate to the private key and installs it in the certificate store (question 1681). FNMT suggests checking the installation as follows: in Chrome and Edge on Windows, in the settings, in the certificate management section, on the “Personal” tab; in Firefox, on the “Your Certificates” tab in the certificate manager (question 1721). If the portal says the certificate has expired or is not yet valid, FNMT gives two causes: the wrong date and time on the computer, or a validity period that really has expired (question 1075).

    At the same step FNMT recommends making a backup. A working backup is a .pfx or .p12 file with the private key (question 1553); a copy without the private key, for example a .cer file, does not work (question 1320). Which file you need and how to install the backup on another computer or phone is covered in the article on transferring the certificate, and installation in different browsers in the section of the article on the certificado digital. Keep the backup file and the password in a safe place and do not give them to anyone.

    Frequently asked questions

    Can I download the FNMT certificate on a different computer, not the one I made the request on?
    No. FNMT requires the certificate to be downloaded on the same computer and under the same user account where the request was made, and, according to its explanation of the technical side, in the same browser too: the private key is stored in the Configurador FNMT-RCM program on that computer. On other devices the certificate is installed from a backup made after the download, as described in the article on transferring the certificate.
    I forgot the password I created when making the request. Can it be recovered?
    No. FNMT warns on the request page that you will need this password again for the download, and that a forgotten password cannot be recovered and the request will have to be started again. This means a new code and a new office visit to verify your identity.
    I went to the office, but the download says “No se ha encontrado el número de petición”. What should I do?
    According to FNMT's explanation, this happens if your identity has not yet been verified at the office or the office did not complete the procedure properly. On the procedure page FNMT says the certificate can be downloaded about an hour after the visit, so first check the details you entered and wait if necessary. If the error does not go away, FNMT asks you to send it an email with the subject “NO GENERADO” stating your NIE, first surname, request code, and the date and office where your identity was verified; the address is in question 1074 on the FNMT website.
    How long do I have to download the certificate after the office visit?
    On the procedure pages FNMT does not give a deadline after which the download is no longer possible, but it advises downloading the certificate as soon as possible. Until the download, do not change anything on the computer: do not format it, and do not update or reinstall the browser or Configurador FNMT-RCM. According to FNMT's explanations, such changes can make the installation fail, and without the private key the whole route has to be started again. The exception is the case where Configurador does not ask for the password during the download: for this FNMT gives a reinstallation procedure with a copy of the .fnmt folder.
    I want to reinstall Windows. Can I reinstall first and download the certificate afterwards?
    No, the order is the other way round. FNMT asks you not to format the computer between the request and the download, and if Configurador is uninstalled before the download and the backup, everything starts again. First download the certificate and save a backup in a .pfx or .p12 file, and after reinstalling, install the certificate from it.
    The whole family is getting certificates on one computer. Can the codes get mixed up?
    They can, and FNMT names this as one of the causes of the error “No existe solicitud de Certificado para los datos que ha introducido”: the code entered was not issued for this document number. Each person enters their own NIE, their own first surname and the code from the email received for their request. If the error persists, FNMT suggests a new request for that NIE and a new office visit with the most recent code received.
