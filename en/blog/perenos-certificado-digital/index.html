    How to move a certificado digital to another computer or phone

    Krepko · 11 November 2026 · ~8 min read
    In short. An FNMT certificate is downloaded only on the computer and under the user account from which the request was made; to another computer or phone it is moved as a copy with the private key — a password-protected .pfx or .p12 file: export on the old device, import on the new one. One certificate can be kept on several devices at once, and there is no need to request a second one: as a general rule, a person has only one valid FNMT individual certificate (persona física), and a new one automatically revokes the previous one when issued (the exception is renewal: in that case the previous one remains valid until its own expiry date). If there is no copy and the old computer does not work, a new certificate is issued; if the device holding the certificate is lost or stolen, FNMT asks you to revoke it. Checked against sede.fnmt.gob.es on 11 November 2026.

You cannot download it again on another computer: the private key is created on a specific computer when the request is made, and the certificate works only together with it.     Why you cannot download the certificate again on a new computer

    When you request a certificate, the FNMT program — Configurador FNMT-RCM — creates a key pair on your computer. The public key goes to FNMT together with the request; the private key stays in the program's storage on that device. When downloading, the program joins the issued certificate with the private key, and without it the certificate will not install (FNMT, question 1681). Hence FNMT's requirements: download from the same computer and under the same user account as when you made the request, and do not format the computer between the request and the download.

    A new computer does not have the private key, so a copy is installed there: the certificate together with the private key in a single password-protected file. FNMT offers to make it as soon as you download the certificate and calls this step recommended. When we handle the digital certificate application for you, we make the copy during installation, on your device, and show you how to use it. If the certificate will not download even on “your own” computer, the reasons are covered in our article on why an FNMT certificate will not download.

    Which file you need: .pfx or .p12, not .cer

    Only a copy with the private key works on another device. It comes with two extensions: .pfx — the way the Windows export wizard saves the copy, and .p12 — the way Firefox and the Mac keychain save it (FNMT, questions 1553 and 1379). For moving the certificate there is no difference: Mac, Android and iPhone accept both files.

    .cer and .crt files contain only the public part of the certificate. You cannot sign with them: such a file is given to people who want to correspond with you securely (question 1063). In Windows you can tell them apart by the icon: the copy with the key shows an envelope with a key, the .cer shows a certificate scroll. If you do not choose the private key option when exporting, you will end up with precisely such a .cer file: in Windows such a file goes into the “Other People” tab (Otras personas) and will not work (question 1320).

    Step 1. Make a copy on the old computer

    The copy is made where the certificate is installed and working. The paths below follow FNMT's instructions; menu item names depend on the version and language of the system.

    Where the certificate is Where to make the copy File
    Windows: Chrome or Edge Settings → manage certificates (in Chrome — certificates imported from Windows) → “Personal” tab → “Export”. In the Windows wizard, choose to export the private key (Exportar la clave privada), leave the format at the default, set a password and a folder .pfx
    Firefox Settings → Privacy & Security → Certificates → View Certificates → “Your Certificates” → select the certificate → Backup → password. On a Mac, the .p12 extension is added to the file name manually .p12
    Mac, Keychain Access Keychain Access → “My Certificates” → select the certificate → File → “Export Items” → password .p12
    Linux: Chrome Settings → Privacy and security → Security → Manage certificates → “Your certificates” → “Export” you choose the name and folder yourself

    You choose the password for the copy yourself. FNMT warns that it will be asked for when installing in another browser or on another computer, so you need to remember it (question 1501). Do not leave it empty: Firefox imports only a password-protected copy (question 1398). If the certificate can no longer be exported again with its private key, FNMT names only one way out — a new certificate (question 1320).

    Step 2. Install the copy on the new computer

    The file is transferred to the new computer and imported where the certificate will be used. Step-by-step import into Chrome, Firefox and Safari is shown in the main article, in the section on installing the certificate in your browser. According to FNMT's instructions, the following matters when importing:

    • Windows: in the import wizard, tick “Mark this key as exportable” (Marcar la clave privada como exportable): that way, according to FNMT's instructions, you will also be able to make a copy with the private key from the new computer (question 1500). For Edge, FNMT also suggests ticking strong private key protection, and if you want the certificate to be password-protected, choosing the high security level and setting a password (question 1552);
    • Firefox: if this browser has not had any certificates before, it will ask you to create its own password for working with the certificate, separate from the copy's password (question 1398);
    • Mac: in Keychain Access, choose “login” and “My Certificates”, then File → “Import Items”, the copy file and its password (question 1380).

    The certificate keeps working on the old device: the same certificate can be installed in several browsers, as well as on a computer and a phone (question 1052 and FNMT's page on the certificate on a mobile device). The copy has the same validity as recorded in the certificate: for those issued now, until 31 December 2028. After renewal, FNMT again recommends making a copy, and it is this new copy that is moved to other devices; how to renew is explained in our article on renewing the certificado digital.

    The certificate on your phone: Android and iPhone

    The same .pfx or .p12 copy as for the computer is installed on the phone.

    Android. Copy the file to the phone's storage, then Settings → Security → Credential storage → Install from phone storage (in the Spanish interface — Ajustes → Seguridad → Almacenamiento de credenciales → Instalar desde la memoria del teléfono). Select the file, enter the copy's password, give the certificate a name without spaces and choose “VPN and apps” (question 1615). Menu items depend on the Android version (question 1653), and on versions before 8 FNMT asks you to also install its root certificate. According to FNMT, a certificate from the system storage works in the standard Android browser and in Chrome, while Firefox for Android and Opera are not suitable for this (question 1610).

    iPhone and iPad. FNMT suggests sending the copy file by email to your own mailbox set up in the Mail app, or saving it to an iCloud folder. On the device, tap the file and go through the installation wizard (question 1707).

    You do not need a second certificate for your phone. The FNMT mobile app issues a new certificate, not a copy of the old one. If you already have a certificate, a new one requested through the app automatically revokes the previous one: a person can have only one individual certificate. The certificate on your computer will then stop working, so FNMT suggests installing the same certificate on your phone from the copy.

    When you cannot do without a new certificate

    This is a general FNMT rule, not only for the app: when a second certificate is issued for the same first name, surnames and document number, the first one is automatically revoked and the new one becomes valid (question 1053 and section 132 of FNMT's certificate issuance rules). A revoked certificate cannot be reactivated (question 1682). The exception is renewal: in that case the previous certificate remains valid until its own date; more in our article on renewal. A new certificate is needed when there is nothing to move the old one from:

    • the certificate is not on any working device and there is no copy, for example the computer broke down or was reinstalled;
    • the copy will not install because its password has been forgotten or it does not contain the private key, and it is no longer possible to make a new one on the original device.

    If the device with the certificate is lost or stolen, FNMT asks you to revoke the certificate, and it is better to do so straight away, without waiting for a new one. Online, it can be revoked if you have the certificate, for example on another device: this requires the AutoFirma program to be installed. If you do not have the certificate at hand, it is revoked in person at an office where identity is verified, or through FNMT's round-the-clock phone line if you know the request code (FNMT page “Anular” and question 1170). For a new certificate, the whole process is repeated: request, office visit, download (question 1320). Where to verify your identity is covered in our article on identity verification for the certificado digital.

    How to store the copy and the password

    The copy with the private key and its password are your entire signature: with them, signatures are made in your name on any device. FNMT writes that a certificate with its private key is exported only for your own use or as a backup, asks you to keep the file in a safe place and never to give a copy of the private key to anyone: the holder is responsible for the certificate (questions 1063 and 1501).

    • keep the copy separate from the computer, on your own storage device or in your own cloud storage, and do not keep the password next to the file;
    • send the email with the copy for your iPhone only to your own mailbox, and delete it after installation;
    • if someone else may have used the copy or the password, revoke the certificate: FNMT explicitly names this case as grounds for revocation;
    • before giving away or selling an old device, make sure the copy works on the new one, and delete from the old one both the certificate and the copy file, if it is saved there (FNMT shows how to delete a certificate in questions 1550, 1400 and 1653).

    Frequently asked questions

    I bought a new computer. Can I download the FNMT certificate onto it again?
    No: the certificate must be downloaded from the same computer and under the same user account from which the request was made. The private key is created at the time of the request and stored on that device, and without it the certificate will not install. On the new computer you install a copy made on the old one — a password-protected .pfx or .p12 file with the private key.
    If I request a new certificate, will the old one stop working?
    Yes, as soon as FNMT issues the new one. As a general rule, a person can have only one valid FNMT individual certificate: when a second one is issued for the same first name, surnames and document number, the first is automatically revoked (FNMT, question 1053 and section 132 of the certificate issuance rules), and a revoked certificate cannot be reactivated (question 1682). Renewal is different: the previous certificate remains valid until its own expiry date. For a second computer or phone you do not need a new certificate; you need a copy of the valid one.
    I made a copy, but the certificate does not work on the new computer. What is wrong?
    One of the reasons FNMT names is that the copy was saved without the private key, as a .cer file. In Windows such a file has a certificate scroll icon, while a correct .pfx or .p12 copy shows an envelope with a key. A file without the key goes into the “Other People” tab and cannot sign (question 1320). Make the copy again on the old computer, choosing to export the private key; if the old certificate is no longer there, the only option left is a new one.
    How do I install a certificado digital on my phone?
    From the same .pfx or .p12 copy as for the computer. On Android, the file is copied to the phone's storage and installed in the security settings, in credential storage, with the copy's password. For iPhone, FNMT suggests emailing the file to yourself in the Mail app or putting it in iCloud and opening it on the device. You do not need to request a second certificate through the FNMT app for this: a new one would revoke the certificate on your computer.
    Can I email the certificate file to myself?
    To yourself, yes: for iPhone, FNMT itself suggests sending the copy by email to your mailbox in the Mail app or putting it in iCloud. After installation, it is better to delete the email with the file. To other people, no: FNMT asks you never to give a copy of the private key to anyone, and the holder is responsible for the certificate. If the file and password may have reached someone else, the certificate is revoked.
    I have forgotten the password for the certificate copy file. What should I do?
    Without the password the copy cannot be installed: FNMT warns that it is asked for when installing on another computer or in another browser. If the certificate is still installed and working on the old device, make a new copy from it: the copy's password is set anew when exporting (question 1501). If it is no longer there, the only option left is to get a new certificate, and the previous one will be revoked automatically.
